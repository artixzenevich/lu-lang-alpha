# lu-lang

![Версия](https://img.shields.io/badge/version-0.8.0--alpha-orange)
![Статус](https://img.shields.io/badge/status-alpha-yellow)
![Python](https://img.shields.io/badge/python-%3E%3D3.10-blue)
![Парсер](https://img.shields.io/badge/parser-Lark-purple)
![Тесты](https://img.shields.io/badge/tests-pytest-brightgreen)

**lu-lang** — учебный язык программирования на русском языке, реализованный на Python. Синтаксис языка целиком состоит из русских ключевых слов: команда вывода записывается как `печать()`, объявление переменной — как `запомнить`. Такой подход позволяет изучать базовые конструкции программирования, не преодолевая дополнительный языковой барьер.

Язык представляет собой внешний предметно-ориентированный язык (DSL), интерпретируемый поверх Python. Реализация состоит из трёх слоёв:

1. лексический и синтаксический анализ — грамматика на библиотеке [Lark](https://lark-parser.readthedocs.io/) с использованием Earley-парсера;
2. построение абстрактного синтаксического дерева;
3. интерпретатор, выполняющий программу и выдающий сообщения об ошибках на русском языке.

## Статус проекта

Текущая версия — **0.8.0-alpha**. Язык находится на ранней стадии разработки: основной набор конструкций реализован и покрыт автоматическими тестами, однако синтаксис и семантика могут изменяться.

## Установка

Требования: Python 3.10 или новее.

### Системная установка команды `lu`

Скрипт `install.sh` создаёт виртуальное окружение в каталоге проекта, устанавливает
пакет и помещает команду `lu` в `~/.local/bin`, откуда она становится доступной
из любого каталога системы:

```bash
./install.sh
```

Дополнительные возможности скрипта:

```bash
./install.sh --prefix DIR    # установить команду в DIR/bin
./install.sh --uninstall     # удалить команду lu
./install.sh --help          # список опций
```

Каталог `~/.local/bin` обычно уже присутствует в `PATH`; в противном случае
необходимо добавить его, как подскажет скрипт.

### Установка в виртуальное окружение

```bash
# из каталога проекта создать виртуальное окружение
python -m venv .venv

# установить пакет в режиме разработки (регистрирует команду lu)
.venv/bin/pip install -e .

# либо установить зависимости вручную
.venv/bin/pip install -r requirements.txt
```

## Использование

Исходный текст программы представляет собой файл в кодировке UTF-8, обычно с расширением `.lu`. Запуск:

```bash
.venv/bin/lu program.lu
```

Эквивалентный способ запуска:

```bash
.venv/bin/python -m lulang program.lu
```

Дополнительные опции команды `lu`:

| Опция        | Назначение                          |
|--------------|-------------------------------------|
| `--show-ast` | вывести дерево разбора и завершиться |
| `--version`  | показать версию интерпретатора       |

### Интерактивный режим

Команда `lu` без аргументов запускает интерактивный режим (REPL) — как
`python` без аргументов. Можно пробовать команды и выражения, получая
результат сразу:

```text
$ lu
lu-lang 0.8.0-alpha — интерактивный режим. Выход: Ctrl+D или выход().
Справка: помощь()
lu> печать(2 + 2)
4
lu> запомнить x = 5
lu> x * 2
10
lu> процедура квадрат(число)
...     вернуть число * число
... конец
lu> выполнить квадрат(4)
lu> выход()
```

Возможности:

- результат выражения печатается сразу: `2 + 2` → `4`;
- незавершённый блок (`процедура ... конец`, `если ... конец`) продолжается
  с приглашением `...`;
- `Ctrl+D` или `выход()` — выход, `Ctrl+C` — очистка текущей строки;
- `помощь()` — справка по интерактивному режиму;
- стрелки вверх/вниз листают историю команд;
- переменные, процедуры и подключённые модули сохраняются в течение сессии.

Примеры программ приведены в каталоге `examples/`:

```bash
.venv/bin/lu examples/hello.lu    # все конструкции языка
.venv/bin/lu examples/модули.lu   # модуль на lu-lang (examples/геометрия.lu)
.venv/bin/lu examples/плагин.lu   # модуль-плагин на Python (examples/текст.py)
.venv/bin/lu examples/файлы.lu    # чтение и запись файлов
.venv/bin/lu examples/переключить.lu  # мультиветвление и преобразование типов
.venv/bin/lu examples/числа_и_массивы.lu  # остаток, перебор, случ(от, до)
.venv/bin/lu examples/черепашка.lu    # графика: черепашка (нужен экран)
```

## Конструкции языка

### Комментарии

- `//` и `#` — однострочные комментарии;
- `/// ... ///` — многострочный комментарий.

### Переменные и типы данных

Переменная объявляется командой `запомнить` и получает значение:

```python
запомнить имя = "Лу"
запомнить возраст = 8
запомнить коэффициент = 3.14
запомнить включено = истина
запомнить пустое = ничего
```

Поддерживаемые типы значений:

| Тип      | Пример                                      |
|----------|---------------------------------------------|
| целое    | `42`                                        |
| дробное  | `3.14`                                      |
| строка   | `"Привет, мир"`                             |
| символ   | `'Л'`                                       |
| булев    | `истина`, `ложь`                            |
| пустое   | `ничего`                                    |
| массив   | `[1, 2, 3]`                                 |
| объект   | `{имя: "Лу", возраст: 8}`                   |

Назначение уже объявленной переменной выполняется без ключевого слова:

```python
запомнить счётчик = 0
счётчик = счётчик + 1
```

### Вывод

Команда `печать()` выводит значение выражения в круглых скобках в стандартный поток вывода:

```python
печать("Привет, мир")
печать(2 + 3 * 4)
```

### Арифметика, строки, сравнения

Доступны операции `+`, `-`, `*`, `/` и скобки для изменения порядка действий. Строки соединяются оператором `+`; число при соединении со строкой преобразуется в её представление:

```python
печать("Лу " + 5)
печать((2 + 3) * 4)
```

Операции сравнения — `=`, `!=`, `<`, `<=`, `>`, `>=`. Логические операторы — `и`, `или`, `не`. Результат сравнения — булево значение.

### Ветвление

Условная конструкция `если / иначе если / иначе` завершается ключевым словом `конец`:

```python
если возраст > 10 то
    печать("Старшеклассник")
иначе если возраст >= 7 то
    печать("Школьник")
иначе
    печать("Дошкольник")
конец
```

Мультиветвление записывается конструкцией `переключить / случай / конец`.
Каждая ветка `случай` перечисляет значения (через запятую), с которыми
сравнивается выражение; выполняется первая подходящая ветка, «проваливания»
нет. Ветка `иначе` — как в `если` — необязательна:

```python
переключить день
случай 1, 7
    печать("Выходной")
случай 2, 3, 4, 5, 6
    печать("Учебный день")
иначе
    печать("Такого дня не бывает")
конец
```

Сравнивать можно числа и строки, а значение под `переключить` — любое выражение.

### Преобразование типов

Команды `тип_число()` и `тип_строка()` превращают значение в число или в строку:

```python
запомнить n = тип_число("42")    # строка «42» стала числом 42
печать(n + 1)                    # 43

запомнить пи = тип_число("3,14") # запятая как десятичный разделитель
печать(тип_строка(42))           # «42» — число как текст
печать(тип_строка(истина))       # «истина»
```

`тип_число` принимает строку (с точкой или запятой) или уже число; если
превратить нельзя — программа остановится с дружеским сообщением.
`тип_строка` записывает значение так же, как `печать`.

### Циклы

Поддерживаются четыре разновидности циклов:

```python
# счётный цикл
для i от 1 до 5
    печать(i)
конец

# цикл с предусловием
запомнить x = 3
пока x > 0
    печать(x)
    x = x - 1
конец

# цикл повторений
повтори 3 раз
    печать("Мяу!")
конец

# перебор элементов массива (или символов строки)
запомнить фрукты = ["яблоко", "груша", "слива"]
для фрукт из фрукты
    печать(фрукт)
конец
```

Для защиты от зависания бесконечные циклы ограничены пределом повторений.

Управление циклом:

- `прервать` — немедленный выход из цикла
- `продолжить` — переход к следующей итерации, пропуская оставшиеся команды

### Остаток от деления

Команда `остаток()` возвращает остаток от деления — удобно для проверки
чётности и циклических алгоритмов:

```python
печать(остаток(7, 3))     # 1
печать(остаток(4, 2))     # 0 — 4 делится на 2 нацело
```

### Процедуры

Процедура определяется конструкцией `процедура` с круглыми скобками для параметров, вызывается командой `выполнить()`, возвращает значение командой `вернуть`:

```python
процедура квадрат(число)
    вернуть число * число
конец

запомнить x = выполнить квадрат(5)
печать(x)
```

Процедуры могут принимать несколько аргументов, вызывать другие процедуры и рекурсивно вызывать самих себя. Процедура без параметров записывается с пустыми скобками:

```python
процедура тест()
    печать("Класс!")
конец
выполнить тест()
```

### Области видимости

Переменные организованы в стек областей: глобальная (уровень программы) и локальные (уровень процедур).

- `запомнить` создаёт переменную **в текущей области** (глобальной или локальной процедуры)
- Переназначение `x = ...` ищет переменную от текущей области к глобальной
- Параметры процедуры автоматически становятся локальными переменными
- Переменная цикла `для i от ... до ...` создаётся в текущей области и доступна после цикла

```python
запомнить x = 10                     # глобальная

процедура тест()
    запомнить x = 5                  # локальная — не затирает глобальную
    печать(x)                        # 5
конец

выполнить тест()
печать(x)                            # 10
```

### Массивы и объекты

Доступ к элементу массива выполняется по индексу, отсчёт начинается с нуля. Длина массива, строки или объекта определяется функцией `длина`:

```python
запомнить фрукты = ["яблоко", "груша", "слива"]
печать(фрукты[0])
печать(длина(фрукты))
```

Поиск элемента в массиве выполняет `найти()` — она вернёт номер элемента или −1,
если его нет (для строк `найти()` ищет подстроку):

```python
запомнить фрукты = ["яблоко", "груша", "слива"]
печать(найти(фрукты, "груша"))    # 1
печать(найти(фрукты, "персик"))   # -1
```

Случайное число в диапазоне — `случ(от, до)` (обе границы включительно),
а `случ(n)` по-прежнему даёт число от 0 до n−1:

```python
печать(случ(1, 6))    # бросок кубика: 1..6
```

Доступ к полю объекта и присваивание выполняются через точку:

```python
запомнить кот = {имя: "Лу", возраст: 5}
печать(кот.имя)
кот.возраст = 6
```

### Ввод

Команда `ввод()` читает значение с клавиатуры. Если введённый текст является числом, он преобразуется в число; в противном случае сохраняется как строка:

```python
запомнить имя = ввод()
печать(имя)
```

### Файлы

Чтение и запись файлов выполняются встроенными командами с префиксом `файл_`.
Путь — строка (имя файла может быть на русском или английском), он считается
относительно каталога, из которого запущена команда `lu`. Текст в файлах —
кодировка UTF-8.

```python
файл_записать("заметки.txt", "Привет, Лу!")   # перезаписать (создаёт файл)
файл_добавить("заметки.txt", "ещё строка")    # дописать в конец
запомнить текст = файл_прочитать("заметки.txt") # прочитать весь файл
печать(файл_существует("заметки.txt"))        # истина / ложь
файл_удалить("заметки.txt")                   # удалить файл
```

При записи число превращается в строку, как в команде `печать`. Если файла нет —
программа остановится с дружеским сообщением («Не нашёл файл "..."»).

### Графика (черепашка)

Встроенный модуль `черепашка` рисует на экране черепашкой, как в языке Logo.
Подключите его и выполняйте команды через точку (нужен графический экран):

```python
подключить черепашка

выполнить черепашка.цвет("синий")
повтори 4 раз
    выполнить черепашка.вперёд(120)
    выполнить черепашка.вправо(90)
конец

выполнить черепашка.готово()   # не закрывать окно с рисунком
```

Команды: `вперёд(шаги)`, `назад(шаги)`, `вправо(угол)`, `влево(угол)`,
`поднять_перо()`, `опустить_перо()`, `цвет(имя)`, `круг(радиус)`,
`точка()`, `скорость(0..10)`, `готово()`. Окно появляется при первом
рисовании и держится открытым после `готово()`, пока его не закроют.

### Модули и библиотеки

Свои модули и библиотеки подключаются командой `подключить`. Имя модуля
пишется без кавычек, можно задать короткое имя через `как`:

```python
подключить математика
подключить математика как м
```

Процедуры модуля вызываются через точку, как поля объекта:

```python
подключить математика
запомнить x = выполнить математика.квадрат(5)
```

Интерпретатор ищет модуль по имени `имя` в таком порядке:

1. рядом с программой — файл `имя.lu`, затем `имя.py`;
2. в каталогах, перечисленных в переменной окружения `LU_PATH`;
3. в `~/.lu-lang/библиотеки`;
4. во встроенной библиотеке, поставляемой вместе с языком.

**Модуль на lu-lang** — обычный файл с процедурами. Он выполняется один раз
при подключении в собственном пространстве имён: его переменные не
смешиваются с переменными программы, а повторный `подключить` не выполняет
тело модуля заново.

```python
# файл математика.lu
процедура квадрат(число)
    вернуть число * число
конец
```

**Модуль-плагин на Python** — файл `.py`, верхнеуровневые функции которого
(без подчёркивания в начале имени) становятся процедурами lu-lang.
Список `__все__` (или `__all__`) ограничивает экспорт:

```python
# файл время.py
import time

def метка():
    return time.time()
```

Встроенные модули доступны сразу: например, `подключить математика` даёт
процедуры `квадрат`, `куб` и `факториал`.

### Импорт отдельных имён

Команда `из ... взять ...` забирает процедуры модуля в текущую область —
дальше их можно вызывать без префикса модуля (как `from X import Y` в Python):

```python
из математика взять квадрат, куб
печать(выполнить квадрат(5))     # 25

# короткое имя для одной процедуры
из математика взять факториал как ф
печать(выполнить ф(5))           # 120

# все процедуры модуля
из математика взять всё
```

Импортированные процедуры выполняются в пространстве имён своего модуля:
их глобальные переменные не путаются с переменными программы. Если в
программе уже есть процедура с таким же именем — она важнее импорта.

Готовые примеры: `examples/модули.lu` с модулем `геометрия.lu` и
`examples/плагин.lu` с плагином `текст.py`.

## Пример программы

```python
запомнить имя = "Лу"
запомнить возраст = 8

печать("Привет, " + имя + "!")
если возраст >= 7 то
    печать("Школьный возраст")
конец

для i от 1 до 3
    печать(i)
конец
```

Результат выполнения:

```text
Привет, Лу!
Школьный возраст
1
2
3
```

## Структура проекта

```text
lu-lang/
├── lulang/             # реализация языка
│   ├── grammar.py      # грамматика на Lark
│   ├── ast_builder.py  # дерево разбора -> узлы AST
│   ├── nodes.py        # типы узлов выражения
│   ├── interpreter.py  # интерпретатор
│   ├── repl.py         # интерактивный режим (REPL)
│   ├── cli.py          # консольная команда lu
│   └── библиотеки/     # встроенные модули (.lu и .py)
├── install.sh          # системная установка команды lu
├── examples/           # примеры программ
├── tests/              # автоматические тесты (pytest)
└── docs/               # описание грамматики и дорожная карта
```

## Разработка и тестирование

Автоматические тесты запускаются средствами pytest:

```bash
.venv/bin/python -m pytest
```

Тесты покрывают лексический анализ, синтаксис, построение AST и поведение интерпретатора. Перед публикацией изменений грамматики требуется полный прогон тестового набора.

Подробное описание грамматики и планов развития приведено в [docs/dsl.org](docs/dsl.org).
