**lu-lang** — учебный язык программирования на русском языке, реализованный на Python. Синтаксис языка целиком состоит из русских ключевых слов: команда вывода записывается как `печать:`, объявление переменной — как `запомнить`. Такой подход позволяет изучать базовые конструкции программирования, не преодолевая дополнительный языковой барьер.

Язык представляет собой внешний предметно-ориентированный язык (DSL), интерпретируемый поверх Python. Реализация состоит из трёх слоёв:

1. лексический и синтаксический анализ — грамматика на библиотеке [Lark](https://lark-parser.readthedocs.io/) с использованием Earley-парсера;
2. построение абстрактного синтаксического дерева;
3. интерпретатор, выполняющий программу и выдающий сообщения об ошибках на русском языке.

## Статус проекта

Текущая версия — **0.1.0-alpha**. Язык находится на ранней стадии разработки: основной набор конструкций реализован и покрыт автоматическими тестами, однако синтаксис и семантика могут изменяться.

## Установка

Требования: Python 3.10 или новее.

### Системная установка команды `lu`

Скрипт `install.sh` создаёт виртуальное окружение в каталоге проекта, устанавливает
пакет и помещает команду `lu` в `~/.local/bin`, откуда она становится доступной
из любого каталога системы:

```bash
./install.sh
```

Дополнительные возможности скрипта:

```bash
./install.sh --prefix DIR    # установить команду в DIR/bin
./install.sh --uninstall     # удалить команду lu
./install.sh --help          # список опций
```

Каталог `~/.local/bin` обычно уже присутствует в `PATH`; в противном случае
необходимо добавить его, как подскажет скрипт.

### Установка в виртуальное окружение

```bash
# из каталога проекта создать виртуальное окружение
python -m venv .venv

# установить пакет в режиме разработки (регистрирует команду lu)
.venv/bin/pip install -e .

# либо установить зависимости вручную
.venv/bin/pip install -r requirements.txt
```

## Использование

Исходный текст программы представляет собой файл в кодировке UTF-8, обычно с расширением `.lu`. Запуск:

```bash
.venv/bin/lu program.lu
```

Эквивалентный способ запуска:

```bash
.venv/bin/python -m lulang program.lu
```

Дополнительные опции команды `lu`:

| Опция        | Назначение                          |
|--------------|-------------------------------------|
| `--show-ast` | вывести дерево разбора и завершиться |
| `--version`  | показать версию интерпретатора       |

Примеры программ приведены в каталоге `examples/`:

```bash
.venv/bin/lu examples/hello.lu
```

## Конструкции языка

### Комментарии

- `//` и `#` — однострочные комментарии;
- `/// ... ///` — многострочный комментарий.

### Переменные и типы данных

Переменная объявляется командой `запомнить` и получает значение:

```python
запомнить имя = "Лу"
запомнить возраст = 8
запомнить коэффициент = 3.14
запомнить включено = истина
запомнить пустое = ничего
```

Поддерживаемые типы значений:

| Тип      | Пример                                      |
|----------|---------------------------------------------|
| целое    | `42`                                        |
| дробное  | `3.14`                                      |
| строка   | `"Привет, мир"`                             |
| символ   | `'Л'`                                       |
| булев    | `истина`, `ложь`                            |
| пустое   | `ничего`                                    |
| массив   | `[1, 2, 3]`                                 |
| объект   | `{имя: "Лу", возраст: 8}`                   |

Назначение уже объявленной переменной выполняется без ключевого слова:

```python
запомнить счётчик = 0
счётчик = счётчик + 1
```

### Вывод

Команда `печать:` выводит значение выражения в стандартный поток вывода:

```python
печать: "Привет, мир"
печать: 2 + 3 * 4
```

### Арифметика, строки, сравнения

Доступны операции `+`, `-`, `*`, `/` и скобки для изменения порядка действий. Строки соединяются оператором `+`; число при соединении со строкой преобразуется в её представление:

```python
печать: "Лу " + 5
печать: (2 + 3) * 4
```

Операции сравнения — `=`, `!=`, `<`, `<=`, `>`, `>=`. Логические операторы — `и`, `или`, `не`. Результат сравнения — булево значение.

### Ветвление

Условная конструкция `если / иначе если / иначе` завершается ключевым словом `конец`:

```python
если возраст > 10 то
    печать: "Старшеклассник"
иначе если возраст >= 7 то
    печать: "Школьник"
иначе
    печать: "Дошкольник"
конец
```

### Циклы

Поддерживаются три разновидности циклов:

```python
# счётный цикл
для i от 1 до 5
    печать: i
конец

# цикл с предусловием
запомнить x = 3
пока x > 0
    печать: x
    x = x - 1
конец

# цикл повторений
повтори 3 раз
    печать: "Мяу!"
конец
```

Для защиты от зависания бесконечные циклы ограничены пределом повторений.

### Процедуры

Процедура определяется конструкцией `процедура`, вызывается командой `выполнить`, возвращает значение командой `вернуть`:

```python
процедура квадрат: число
    вернуть число * число
конец

запомнить x = выполнить квадрат: 5
печать: x
```

Процедуры могут принимать несколько аргументов, вызывать другие процедуры и рекурсивно вызывать самих себя. Процедура без параметров вызывается без аргументов; двоеточие после имени в этом случае необязательно:

```python
процедура тест:
    печать: "Класс!"
конец
выполнить тест:
выполнить тест
```

Семантическая особенность вызова: арифметическое выражение, следующее за аргументами, относится к аргументу вызова, а не вычисляется после него. Например, `выполнить плюс_один: 1 + 2` передаёт процедуре аргумент `1 + 2`. Для явного управления порядком вычислений выражение заключается в скобки: `(выполнить плюс_один: 1) + 2`.

### Массивы и объекты

Доступ к элементу массива выполняется по индексу, отсчёт начинается с нуля. Длина массива, строки или объекта определяется функцией `длина`:

```python
запомнить фрукты = ["яблоко", "груша", "слива"]
печать: фрукты[0]
печать: длина(фрукты)
```

Доступ к полю объекта и присваивание выполняются через точку:

```python
запомнить кот = {имя: "Лу", возраст: 5}
печать: кот.имя
кот.возраст = 6
```

### Ввод

Команда `ввод:` читает значение с клавиатуры. Если введённый текст является числом, он преобразуется в число; в противном случае сохраняется как строка:

```python
запомнить имя = ввод:
печать: имя
```

## Пример программы

```python
запомнить имя = "Лу"
запомнить возраст = 8

печать: "Привет, " + имя + "!"
если возраст >= 7 то
    печать: "Школьный возраст"
конец

для i от 1 до 3
    печать: i
конец
```

Результат выполнения:

```text
Привет, Лу!
Школьный возраст
1
2
3
```

## Структура проекта

```text
lu-lang/
├── lulang/             # реализация языка
│   ├── grammar.py      # грамматика на Lark
│   ├── ast_builder.py  # дерево разбора -> узлы AST
│   ├── nodes.py        # типы узлов выражения
│   ├── interpreter.py  # интерпретатор
│   └── cli.py          # консольная команда lu
├── install.sh          # системная установка команды lu
├── examples/           # примеры программ
├── tests/              # автоматические тесты (pytest)
└── docs/               # описание грамматики и дорожная карта
```

## Разработка и тестирование

Автоматические тесты запускаются средствами pytest:

```bash
.venv/bin/python -m pytest
```

Тесты покрывают лексический анализ, синтаксис, построение AST и поведение интерпретатора. Перед публикацией изменений грамматики требуется полный прогон тестового набора.

Подробное описание грамматики и планов развития приведено в [docs/dsl.org](docs/dsl.org).
