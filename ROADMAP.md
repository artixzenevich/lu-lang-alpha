# Дорожная карта lu-lang

Актуальная версия: [0.6.0-alpha](CHANGELOG.md)

---

## ✅ 0.2.0-alpha — Символы *(реализовано)*

- `код(символ)` — получение Unicode-кода символа
- `символ(число)` — получение символа по коду

## ✅ 0.3.0-alpha — Математика, строки, массивы *(реализовано)*

- Индексация строк: `s[0]`
- Строковые операции: `найти()`, `подстрока()`
- Операции с массивами: `добавить()`, `удалить()`
- Математические функции: `корень()`, `модуль()`, `случ()`, `округлить()`

## ✅ 0.3.1-alpha — Новые строковые операции *(реализовано)*

- `вверх()`, `вниз()`, `заменить()`, `разделить()`, `соединить()`,
  `начинается()`, `заканчивается()`, `перевернуть()`

## ✅ 0.3.2-alpha — Прерывание циклов *(реализовано)*

- `прервать` — досрочный выход из цикла
- `продолжить` — переход к следующей итерации

## ✅ 0.4.0-alpha — Модульность *(реализовано)*

- `подключить имя` — подключение модуля (`.lu` или `.py`), алиас через `как`
- Квалифицированные вызовы: `выполнить модуль.процедура(...)`
- Поиск модулей: каталог программы → `LU_PATH` → `~/.lu-lang/библиотеки` →
  встроенная библиотека
- Модули на Python: верхнеуровневые функции становятся процедурами, `__все__`
  ограничивает экспорт
- Импорт имён: `из математика взять квадрат` (как `from X import Y`), алиас
  через `как`, дикий импорт `из математика взять всё`
- Модуль исполняется один раз при подключении в собственном пространстве имён
- Примеры: `examples/модули.lu` + `геометрия.lu`, `examples/плагин.lu` + `текст.py`

## ✅ 0.4.1-alpha — Интерактивный режим (REPL) *(реализовано)*

- `lu` без аргументов — REPL как в Python
- Выражение сразу печатает результат; незавершённый блок — приглашение `...`
- `помощь()` и `выход()`, Ctrl+C — очистка, Ctrl+D — выход, история стрелками
- Состояние сессии (переменные, процедуры, модули) живёт между командами

## ✅ 0.5.0-alpha — Работа с файлами *(реализовано)*

- `файл_прочитать(путь)` — чтение всего файла в строку
- `файл_записать(путь, текст)` — перезапись файла
- `файл_добавить(путь, текст)` — дописывание в конец файла
- `файл_существует(путь)` — проверка существования файла
- `файл_удалить(путь)` — удаление файла
- Путь — строка (русское или английское имя), UTF-8, дружеские ошибки
- Пример: `examples/файлы.lu`

## ✅ 0.6.0-alpha — Переключить и преобразование типов *(реализовано)*

- `переключить / случай / конец` — мультиветвление, первое совпадение, `иначе`
- Значения веток через запятую, сравнение по `=` (числа и строки)
- `тип_число()` — строка (точка или запятая) в число
- `тип_строка()` — значение в строку, как `печать`
- Пример: `examples/переключить.lu`
