* lu-lang: язык, грамматика

*Lu* - предметно-ориентированный язык программирования *(Domain-Specific Language)*, который создается специально
для школьников 5-7 классов с целью обучения основам программирования и алгоритмизации. Язык получил свое название в честь
кота автора по кличке Лу. Язык является *внешним DSL* и построен над языком программирования *Python*, что в свою очередь
должно обеспечить простоту и понятность, как в чтении программ, так и в написании. Язык предназначен как вводный и должен передавать
суть программирования. Написание программ выполняется с использованием простейших конструкций и семантики с использованием кириллицы.

Все описанное ниже реализовано и работает в версии *0.1.0 alpha*.

** Устройство
Язык состоит из трёх слоёв:

1. *Лексер и парсер* (=lulang/grammar.py=) — грамматика на великолепной
   библиотеке [[https://lark-parser.readthedocs.io/][Lark]]. Превращает текст
   в дерево разбора. Мы используем Earley-парсер, поэтому язык можно расширять
   почти как угодно (в том числе левая рекурсия работает). Редкие
   неоднозначности (например, сколько аргументов «съест» вызов
   =выполнить привет: 1 + 2=) раскрываются жадно — в пользу вызова.
2. *AST* (=lulang/nodes.py=, =lulang/ast_builder.py=) — упрощённое дерево
   программы: =PrintStmt=, =AssignStmt=, =BinOp=, =Number=, =String=,
   =Variable=, а также узлы для условий, циклов, процедур, массивов и объектов.
   Здесь удобно делать проверки (например, «используется ли переменная до
   команды =запомнить=").
3. *Интерпретатор* (=lulang/interpreter.py=) — идёт по инструкциям сверху вниз
   и считает результат. Ошибки выводит по-русски и по-дружески:
   =Не знаю, что такое ...=, =На ноль делить нельзя!=.

** Как добавить новую часть языка

Добавить, например, новую команду вывода:

1. Ищем место в грамматике — например, правило =print_stmt=.
2. Добавляем вариант в =grammar.py=.
3. Добавляем проверку на новую команду в =ast_builder.py=.
4. Пишем, что она делает, в =interpreter.py=.
5. Пишем пример в =examples/= и один тест в =tests/=.

*Важно*: после изменения грамматики всегда запускать =pytest=.

** Ключевые слова (зарезервированные)

Их нельзя использовать как имена переменных. Слова с двоеточием (=печать:=, =ввод:=, =процедура:=) вводятся с двоеточием.

| Слово         | Назначение                              |
|---------------+-----------------------------------------|
| =запомнить=   | Объявление переменной                   |
| =печать:=     | Вывод сообщения в терминал              |
| =ввод:=       | Чтение значения с клавиатуры            |
| =длина=       | Длина массива, строки или объекта       |
| =если= =то=   | Начало ветвления и условие              |
| =иначе=       | Ветка «иначе», в т.ч. =иначе если=      |
| =конец=       | Окончание блока (ветка, цикл, процедура)|
| == = != = < = > = <= = >= | Сравнение значений          |
| =и= =или= =не=| Логические операции                    |
| =пока=        | Цикл с условием                         |
| =для= =от= =до= | Цикл со счётчиком                     |
| =повтори= =раз= | Цикл-повторение                       |
| =процедура:=  | Объявление процедуры                    |
| =выполнить=   | Вызов процедуры                         |
| =вернуть=     | Возврат значения из процедуры           |
| =истина= =ложь= | Булевы значения                      |
| =ничего=      | Пустое значение                         |

** Грамматика
*** Комментарии

Комментарий — это текст, который компьютер игнорирует. Он нужен, чтобы
объяснять, что делает программа.

- Однострочный — начинается с =//= или с =#=,
- Многострочный — начинается с =///= и заканчивается =///=.

*Пример:*
#+begin_src
// Привет мир
# тоже комментарий

///
Это моя первая программа
на языке Lu
///
#+end_src

*** Переменные

Язык *Lu* является динамически типизируемым, поэтому тип переменной не
указывается. Для объявления переменной используется =запомнить=. Уже
объявленной переменной можно присвоить новое значение просто так.

*Пример:*
#+begin_src

запомнить яблоки = 2
запомнить имя = "Даниил"
яблоки = яблоки + 1   // переназначение без «запомнить»

#+end_src

*** Типы данных

| Тип    | Как пишется                      | Пример                                       |
|--------+----------------------------------+----------------------------------------------|
| Число  | Целое или дробное                | =42=, =3.14=                                 |
| Строка | Указывается в двойных кавычках   | ="Привет мир!"=                              |
| Символ | Указывается в одинарных кавычках | ='а'=, ='Л'=, ='!'=                          |
| Булево | Ключевые слова                   | =истина=, =ложь=                             |
| Массив | В квадратных скобках             | =[1, 2, 3]=, =["яблоко", "груша", "персик"]= |
| Объект | В фигурных скобках               | ={имя: "Варвара", возраст: 5}=               |
| Пусто  | Ключевое слово                   | =ничего=                                     |

*** Стандартные команды

Команда =печать:= выводит данные в терминал. Команда =ввод:= ожидает ввод
от пользователя в терминале. Если введённое похоже на число, так и станет
числом — иначе останется строкой. Команда =длина(выражение)= возвращает
длину массива, строки или объекта.

#+begin_src
// результат команды ввод присвоится переменной
запомнить имя = ввод:

// отобразит содержимое переменной имя в терминале
печать: имя

// выведет число символов
печать: длина(имя)
#+end_src

*** Операторы сравнения и логики

- = =, != = (равно, не равно)
- =<, >, <=, >== (меньше, больше, не больше, не меньше)
- =и=, =или=, =не=

*Пример:*
#+begin_src

если возраст >= 5 и возраст < 10 то
    печать: "Школьный возраст"
конец

#+end_src

*** Операторы ветвления

Для условий используется =если / то / иначе если / иначе / конец=.

*Пример:*
#+begin_src

если возраст > 5 то
    печать: "Ты уже большой!"
иначе если возраст = 5 то
    печать: "Тебе ровно пять!"
иначе
    печать: "Ты ещё малыш."
конец

#+end_src

Блоки внутри =если=, циклов и процедур заканчиваются словом =конец=.
Внутри блоков можно вкладывать другие блоки.

**** Циклы

Цикл со счетчиком

*Пример:*
#+begin_src

для i от 1 до 5
    печать: "Шаг номер " + i
конец

#+end_src

Цикл с условием, пока что-то истинно

*Пример:*
#+begin_src

запомнить x = 10
пока x > 0
    печать: x
    x = x - 1
конец

#+end_src

Цикл повторений

*Пример:*
#+begin_src

повтори 3 раз
    печать: "Мяу!"
конец

#+end_src

Чтобы программа не «зависала», бесконечные циклы останавливаются
с дружеским сообщением.

*** Функции (Процедуры)

Используется ключевое слово =процедура:=. После двоеточия указываются
параметры. Процедура может создаваться и без параметров, но обязательно
с двоеточием на конце. Для вызова процедуры перед её именем пишется ключевое
слово =выполнить=. Для возврата значения используется =вернуть=.

*Пример:*
#+begin_src

# Объявление
процедура квадрат: число
    вернуть число * число
конец

процедура привет: имя, возраст
    печать: "Привет, " + имя + ", тебе " + возраст + " лет."
конец

# Вызов
запомнить x = выполнить квадрат: 5
печать: x   # Выведет 25

выполнить привет: "Лу", 5

#+end_src

Если в вызове нужно передать результат арифметического выражения,
заключите его в скобки: =выполнить квадрат: (3 + 2)=. Процедуры можно
вызывать из других процедур, в том числе из самих себя (рекурсия).

*** Работа с массивами и объектами

Работа с массивами.

*Пример:*
#+begin_src

запомнить фрукты = ["яблоко", "груша", "слива"]

# Доступ по индексу (с нуля, как везде)
печать: фрукты[0]   # яблоко

# Изменение
фрукты[1] = "банан"

# Длина массива
печать: длина(фрукты)

#+end_src

Работа с объектами.

*Пример:*
#+begin_src

запомнить кот = {имя: "Лу", возраст: 5}

# Доступ через точку
печать: кот.имя     # Лу
печать: кот.возраст # 5

# Изменение
кот.возраст = 6
кот.цвет = "рыжий"  # Добавление нового поля

#+end_src

** Формальное описание грамматики

Ниже грамматика языка в расширенной форме Бэкуса — Наура (EBNF).
Здесь ={ ... }= означает «ноль или больше раз», =[ ... ]= — «необязательно»,
а слова в кавычках («печать») — ключевые слова. =имя= — имя переменной или
процедуры (кириллица, латиница, символ подчёркивания; не ключевое слово).

#+begin_example
программа   = { инструкция } .

инструкция  = печать | вызов | присваивание
            | если | пока | для | повтори
            | процедура | вернуть | пустая.

печать      = "печать" ":" выражение .
вызов       = "выполнить" имя [ ":" список_выражений ] .
присваивание = "запомнить" имя "=" выражение
            | куда "=" выражение .
куда        = имя | имя "." имя | имя "[" выражение "]" .

если        = "если" выражение "то" { инструкция }
            { "иначе если" выражение "то" { инструкция } }
            [ "иначе" { инструкция } ] "конец" .
пока        = "пока" выражение { инструкция } "конец" .
для         = "для" имя "от" выражение "до" выражение
            { инструкция } "конец" .
повтори     = "повтори" выражение "раз" { инструкция } "конец" .

процедура   = "процедура" имя ":" [ список_имён ] { инструкция } "конец" .
вернуть     = "вернуть" [ выражение ] .

выражение   = или .
или         = и { "или" и } .
и           = не { "и" не } .
не          = "не" не | сравнение .
сравнение   = сумма [ ( "=" | "!=" | "<" | ">" | "<=" | ">=" ) сумма ] .
сумма       = множитель { ( "+" | "-" ) множитель } .
множитель   = унарный { ( "*" | "/" ) унарный } .
унарный     = "-" унарный | значение .

значение    = число | строка | символ
            | "истина" | "ложь" | "ничего"
            | имя | вызов | массив | объект
            | длина | ввод | "(" выражение ")" .
длина       = "длина" "(" выражение ")" .
ввод        = "ввод" ":" .
массив      = "[" [ список_выражений ] "]" .
объект      = "{" [ имя ":" выражение { "," имя ":" выражение } ] "}" .

вызов       = "выполнить" имя [ ":" список_выражений ] .
список_выражений = выражение { "," выражение } .
список_имён  = имя { "," имя } .
#+end_example

Последовательность операторов в выражении подчиняется обычному порядку
старшинства: сначала =* / и значок минус перед значением=, затем =+ -=,
затем сравнения, затем =не=, =и=, и уже потом =или=. Скобки =( )= меняют
этот порядок.
